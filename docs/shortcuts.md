# Useful shortcuts

Chaos, Force, and Wish can trigger shortcuts that macOS apps already recognize. Enable the corresponding MegaKey rule, then use one right-hand modifier instead of pressing two modifiers together:

- **❋ Chaos**: <kbd>Right Ctrl</kbd> = <kbd>Opt</kbd>+<kbd>Cmd</kbd>
- **▲ Force**: <kbd>Right Option</kbd> = <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>
- **⭑ Wish**: <kbd>Right Cmd</kbd> = <kbd>Ctrl</kbd>+<kbd>Opt</kbd>

These are examples of **existing shortcuts**, not actions added by MegaKey's optional clipboard demo. App settings, other remappers, and macOS shortcuts can override them. The physical position of Option/Command may also differ on PC keyboards used with a Mac.
